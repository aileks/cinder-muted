# Cinder Muted for dwmblocks

Copy the contents of `config.h` into your dwmblocks-async checkout and rebuild.

The `^c#...^` codes only render if dwm runs the `status2d` patch (see [dwm](../dwm/README.md)).
The block commands (`your-script-1`, `your-script-2`, ...) are placeholders; point them at your own scripts and keep the `^c#...^` prefix.
