# Cinder Muted for Stylus

A global userstyle with the muted palette. It is deliberately conservative: `color-scheme: dark` plus base surfaces, letting sites that define their own colors mostly win. Extend it per-site from the CSS variables it exposes (`--cinder-background`, `--cinder-accent`, and friends).

## Install

Install the [Stylus extension](https://github.com/openstyles/stylus), then either import the file through the Stylus backup importer (Stylus Manage > Import) or create a new style, paste the contents of `cinder-muted.user.css`, and save.
